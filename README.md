# Workforce Analytics and Business Risk Analysis (Excel Dashboard)

This Excel dashboard provides insights into workforce KPIs, attrition trends, absenteeism patterns, salary cost distribution, and business risk indicators.

## 📊 Tools Used
- Microsoft Excel
- Pivot Tables
- Slicers & Timelines
- Conditional Formatting
- Charts & KPI Cards

## 🧠 Key Insights
- Attrition rate by department and job role  
- Absenteeism trends across months  
- Salary cost distribution  
- High-risk employee identification  
- Workforce demographics overview  

## 📁 Files Included
- `Workforce_Analytics_Dashboard.xlsx`
- Supporting data files (if any)

## 🧰 Dashboard Features
- Interactive slicers for Department, Job Role, Gender, Risk Category  
- Dynamic charts and KPI cards  
- Clean layout for HR and management reporting
